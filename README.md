# CPM 5.0 — Hệ thống Quản lý Dự án Xây dựng (BQLDA Tân Phú)

- **Backend**: Google Apps Script (`02_Process/Code.gs`) + Google Sheets
- **Frontend nguồn**: `03_Outputs/` (deploy lên Apps Script Web App)
- **Bản tĩnh Vercel**: `dist_vercel/` (build bằng `build_vercel.py`, gọi API về GAS Web App)

Modules: Dashboard, Dự án, Nhiệm vụ Kanban, Hợp đồng, Gantt, Nhân sự, Nhà thầu,
Tư vấn giám sát (TVGS), Báo cáo ngày, Quyết toán DAHT (TT 91/2025/TT-BTC).
